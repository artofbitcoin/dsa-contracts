# 4. Limites

Ce parcours couvre le modèle de compte, les connecteurs et les contrôles visibles dans dsa-contracts. Le dépôt comporte aussi des audits, scripts et tests ; aucun d’eux n’a été exécuté ici.

Une intégration réelle doit vérifier les versions, les adresses, les approvals, les callbacks externes, les limites de gas et la gouvernance des connecteurs. Le code historique n’est pas une garantie de compatibilité avec les déploiements actuels.

Aucune installation, compilation, exécution ou validation de test n’a été réalisée. Ce document est pédagogique et ne remplace pas un audit.
